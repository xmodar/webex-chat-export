# Privacy policy

_Webex Chat Export · last updated 2026-10-29_

Webex Chat Export collects nothing and sends nothing anywhere.

- **What it reads:** the chat messages, sender names, times, reactions and your
  own display name, as shown in a Webex meeting open in your browser on
  `*.webex.com`. It reads nothing on any other site.
- **Where the data goes:** only into the file you export, saved where you
  choose.
- **In memory:** while a meeting page is open, the extension keeps the chat
  messages it has seen in that page's memory, so an export can include
  messages Webex no longer shows. This is never written to disk and is
  cleared when the page is reloaded or closed.
- **What it stores:** only if you turn on the optional close reminder (off by
  default), it keeps, while a meeting runs, a copy of the chat in
  the extension's local storage. This lets it offer an export if the
  meeting tab closes before you export. The copy never leaves your computer.
  It is deleted when you choose **Discard**, or 14 days after the meeting.
  It is also deleted when you remove the extension.
- **Settings:** your export options (format, name override, time zone, sheet
  direction, reminder default) are kept in the same local storage.
- **No network requests:** the extension makes none of its own. It has no
  analytics, tracking, ads or remote code.
- **No sharing:** nothing is sold, shared or transferred to anyone.

The source code is public at https://github.com/xmodar/webex-chat-export.
Questions: open an issue there.
