Webex Chat Export

Format

Options

Off by default. While it is on, the extension also saves a copy of the chat on this computer during meetings, so it can still be exported if the tab closes first. That extra work can make Webex slower or less responsive, especially in long or busy meetings.

Keep this tab on the meeting while it runs: the chat panel is scrolled and each direct chat is opened in turn. You'll be asked where to save the file.

Webex drops old messages from long chats, so the extension keeps every message it has seen in memory while the meeting page is open, and exports those too. Reloading the meeting page clears that memory.
